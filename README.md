# Global Sales Data Analysis Using SQL

This repository contains SQL queries and Python scripts to perform comprehensive analysis on the Global Superstore sales dataset.  
The focus is on extracting key insights about sales performance, customer segmentation, shipping patterns, and product categories.

---

## Contents

- SQL queries for sales insights  
- Python scripts to execute queries and process results  
- Dataset: [Global Superstore](https://github.com/yannie28/Global-Superstore/blob/master/Global_Superstore_100.csv)
